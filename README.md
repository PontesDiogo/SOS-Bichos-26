# SOS Bichos 🐾

Sistema web para registro e acompanhamento de denúncias relacionadas a animais.

## 🚀 Funcionalidades

- Cadastro de usuário
- Login com autenticação
- Registro de denúncias
- Listagem de denúncias

## 🛠️ Tecnologias

- React + TypeScript
- Supabase (Backend + Banco de Dados)
- Vite

## ▶️ Como rodar

```bash
npm install
npm run dev
